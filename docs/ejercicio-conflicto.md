# Ejercicio controlado de integración — ACT-12

Este archivo se utiliza exclusivamente para demostrar un conflicto
entre ramas del mismo autor. No define reglas de la aplicación.

## Texto de trabajo

Mensaje de confirmación: Reserva confirmada correctamente.

## Contexto

Dos ramas modificarán el mensaje de confirmación desde una base común.
La resolución conservará una redacción que combine sus aportaciones.

Modalidad individual: el ejercicio no acredita trabajo simultáneo
de varios integrantes.
